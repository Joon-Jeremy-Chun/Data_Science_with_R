1. Read the preserved 1.1 introduction notes on features, outcomes and predictions.
2. Run the new 2.1 offline Iris companion and inspect its split, training-only scaling and confusion matrix.
3. Continue with the owner’s separate classical/deep-learning notebook repositories for broader models.

The original introduction contains comments. The separate new reference uses built-in iris, base scaling and class::knn.

## Results and limitations

The original introduction file had pre-existing owner edits in the original worktree and was not changed or included in this maintenance publication. One 45-row test split is a learning check, not an algorithm ranking.

Read [repair evidence](../docs/REPAIRS.md) and [reproduction/side effects](../docs/REPRODUCIBILITY.md). Historical numeric comments are preserved; a successful smoke run does not validate every statistical interpretation.
